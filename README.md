# crypto-saas-landing

A polished, mobile-friendly crypto/SaaS landing page for **NOVA**, built as a self-contained static site.

## Preview

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Included

- Dark, premium gradient design with responsive navigation and mobile menu
- Hero section with animated token illustration, network highlights, and calls to action
- Feature cards for speed, fees, and security
- Interactive token allocation breakdown
- Four-phase roadmap
- Simulated wallet chooser modal (does not connect to a real wallet or perform transactions)
- Social links, smooth scrolling, hover effects, and reduced-motion support

No build tools or dependencies are required. Google Fonts are loaded remotely; system fallbacks are provided.
